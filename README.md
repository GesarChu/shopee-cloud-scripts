# shopee-cloud-scripts（電商線 Nora → 雲端 session）

> 蝦皮分潤短影音的「寫腳本」工作搬到雲端做，本機 Nora 專心顧生成與驗片。
> 建立：2026-09-28 電商線第 30 棒。本儲存庫**只放寫腳本需要的東西**，⛔ 不含任何憑證、權杖、帳號資料。

## 背景（一段話）

我們做 AI 人物短影音幫蝦皮商品導購。每支片＝**5 個鏡頭**，每鏡一個地點、一句台詞（約 3 秒）。
每鏡要兩份提示詞：
1. **首幀指令**（`_qwen指令/q_<鏡>.txt`）：給圖片模型 Qwen-Image，把人物照（image 1）＋商品照（image 2）畫成該鏡的第一格。
2. **影片提示詞**（`prompt_<鏡>D.txt`）：給影片模型 MiniMax H3，從首幀生 5 秒會講話的片段；台詞用官方標籤 `<d>[Chinese] …</d>`。
另外一份 **口白腳本**（`口白腳本_<鏡>D.txt`）＝兩個半句各一行，給驗片比對用。

現在這些檔是 `legacy/` 裡一串互相 `exec` 的產生器寫出來的，很難改、也很難交給別人。

## 工單 #1：把產生器整理成一支乾淨的工具（這次只做這件）

### 要做的
1. 讀 `legacy/` 六支檔（執行順序：`_gen_new0928e.py`／`f.py` → exec `c.py` 開頭 → exec `b.py` 開頭 → exec `_gen_batch0928.py` 開頭 → exec `_gen_new0927.py` 開頭），搞懂 `hold()`、`shot2()`、`five2()` 怎麼組字串。
2. 寫 `genlib.py`：一個模組，**不准 exec 其他檔**，所有文字模板集中在一處，輸出資料夾用參數給。
3. 定一個**商品規格檔格式** `spec/<商品>.json`（人物描述、5 個場景、商品外觀描述、拿法、5 句台詞、5 套服裝……，legacy 呼叫 `five2()` 時給的參數都要能表達），寫 `spec/TTL花雕雞麵.json`、`spec/歐萊德咖啡因洗髮精.json` 兩份，並附 `spec/README.md` 說明每個欄位。
4. 寫 `make.py spec/<商品>.json --out out/<包名>`：讀規格檔 → 用 genlib 寫出上面三種檔。
5. **驗收：`make.py` 產出的 30 個檔，要跟 `golden/` 裡的 30 個檔逐位元組相同**（`golden/` 就是本機現在實際在用的檔）。寫 `test_golden.py`（pytest 或直接 python 都可）自動比對。

### ⚠️ 已知差異（不是 bug，要照 golden 做）
legacy 原樣跑出來的 `prompt_*D.txt`，跟 golden 只差在「手」的寫法：golden 一律不寫左右手——
`in her right hand` → `in one hand`、`her left hand …` → `… her other hand`（2026-09-27 起的規則：圖片模型常把左右手畫反，影片提示詞寫左右會打架）。
genlib 要直接產出 golden 的寫法，不是事後取代。

### 驗收標準（全過才算完成）
| # | 條件 |
|---|---|
| 1 | `python test_golden.py` 全部通過：30/30 檔逐位元組相同（UTF-8、`\n` 換行） |
| 2 | `genlib.py`、`make.py` 沒有 `exec`、沒有寫死的本機路徑（`C:/`、`E:/`、中文絕對路徑都不行） |
| 3 | `spec/README.md` 說清楚每個欄位；看完就能照著寫新商品 |
| 4 | `python tools/script-lint.py out/<包>/口白腳本_*D.txt` 能跑（規則檔不用改） |

### 產出與回報
- 程式放根目錄；規格檔放 `spec/`；試產出放 `out/`（`out/` 不用提交大檔，文字檔可以提交）。
- **報告寫進 `out/工單1-報告.md`，第一段就寫結論**（達標／未達標、哪條沒過），接著寫：你改了什麼、規格檔格式、你覺得 legacy 寫法有問題的地方。
- ⛔ 做不到的要明講，⛔ 不准用猜的內容填補後當成完成。
- ⛔ **重要發現一律寫進 `out/` 報告，不要只在對話裡講**（本機讀不到你的對話）。
- 做完 commit＋push 到 `main`。

### 紅線
- ⛔ 不要改 `golden/` 裡任何檔。
- ⛔ 不要新增任何帶金鑰／權杖的檔；也不需要連任何外部網站（純文字處理）。
- ⛔ 不要改動提示詞的「內容」（措辭、規則句）——這張單只重構程式，輸出要一字不差。
