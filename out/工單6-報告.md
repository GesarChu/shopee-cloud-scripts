## 2. 分組怎麼判
1. **品名正規化**：品名先 NFKC（全形英數變半形），拿掉 `promo_words`、`capacity_pattern`（500ml、110抽x12包、x3入）、拿空了的括號（【免運現貨】）、其他括號符號。
   - 結果當「組名」；每列拿掉了哪些字記在 `分組.json` 的「拿掉」。
2. **品牌**：第一個詞。
   - 品名沒空格（「晴空洗碗精檸檬500ml x3入」）或第一個詞黏著系列（「晴空洗碗精 檸檬」）：拿其他列或做過清單出現過的品牌當前綴比。
   - 都對不到：標「品牌待人判」。
3. **口味**：`flavor_words` 裡**單獨成詞**的才算口味。沒有單獨成詞的，才在詞裡找「不是品類字」的口味字。
   - 所以「脆烤海苔」的「海苔」是品名主體，「梅子」才是口味。
   - 「洗碗精檸檬」的「檸檬」算口味（檸檬不是品類字）。
4. **系列**＝品牌之後、拿掉口味剩下的字（去空白）。**(品牌, 系列, 口味) 完全一樣才同組**。
   - 口味不同一定不同組；詞序不同（「晴空 檸檬 洗碗精」）會併。
5. **分組待人判**（只列出、⛔ 併），要同時符合：
   - 品牌一樣、組不一樣；
   - 口味不是「兩邊都有而且不同」（口味不同是確定的不同組）；
   - 系列含同一個品類字典的字，或一邊的系列包含另一邊。
   - 這個判法不用任何相似度門檻，因為規則檔沒給這種數字，程式也不能自己寫死。
6. **樣本**：16 列分 13 組。
   - 列 3「【免運現貨】晴空洗碗精檸檬500ml x3入」拿掉「免運、現貨、500ml x3入」後，跟列 1、2 同組。
   - 列 15 綠茶、列 5 梅子各自一組。
   - 列 9／10「舊識牌」系列不同（豆漿／糙米米漿），不同組，也不算待人判（品類字一個是「豆漿」、一個是「米漿」）。

## 3. 哪些情況會判錯（另外造一份 16 列的刁鑽品名實際跑過）
| 品名 | 程式怎麼判 | 對不對 |
|---|---|---|
| 「晴空 檸檬 洗碗精」、「晴空洗碗精 檸檬」 vs「晴空 洗碗精 檸檬」 | 同組 | 對 |
| 「山嵐脆烤海苔原味34g」 vs「山嵐 脆烤海苔 原味 34g」 | 同組 | 對 |
| 「大成 檸檬紅茶」 vs「大成 紅茶 檸檬」 | 同組（口味檸檬、系列紅茶） | 多半對；但「檸檬紅茶」如果是一個產品名、另有原味紅茶，要人看 |
| 「晴空 洗碗精 檸檬 **新包裝**」 | 另一組，列進待人判 | **錯**（新舊包裝應該同組）⇒ 建議 promo_words 加「新包裝」 |
| 「舒潔 衛生紙 抽取式」 vs「舒潔 抽取式衛生紙」 | 不同組，列進待人判 | 保守；人看一眼就能併 |
| 「Kleenex舒潔 抽取式衛生紙」 vs「舒潔 …」 | 不同品牌、不同組，**沒有**列進待人判 | **錯**；中英品牌並列的要靠人看，或做一張品牌別名表 |
| 「晴空 洗碗精」（沒寫口味） vs「晴空 洗碗精 檸檬」 | 不同組，列進待人判 | 對（不知道沒寫的是不是檸檬） |
| 「可口 巧克力 120g」 | 口味「巧克力」、系列空白 | 顯示怪；「巧克力」既是品類字也是口味字，單獨成詞時當口味 |
| 「寶寶 濕紙巾」（品牌叫寶寶） | 品類衝突（生活用品／嬰兒），留在候選 | 字典連品牌名一起比，所以衝突；不會誤排除，交給人判 |
| 「晨光 牛奶 沐浴乳」 | 品類「零食飲料、生活用品」 | 半錯（牛奶是香味），沒有後果，但品類欄會怪 |
| 「大成 檸檬紅茶」 | 未分類（待人判） | 字典沒有「紅茶」⇒ 建議補 |
| 價格「$59 - $99」 | 讀不到，每單約 $ 算不出來 | 照「讀不懂就標讀不到」；要取下限要規則檔加鍵 |

另外幾個要知道的：
- **品牌是猜的**：靠「第一個詞」和「別列出現過的品牌」。整份 CSV 只有一列、又沒空格的品名，品牌會對不到（標「品牌待人判」），做過清單也只能用前綴比。
- **做過清單的系列用「包含」比**：「豆漿」會對到「黑豆漿」「無加糖豆漿」。系列字寫太短（例「乳」）會誤殺，清單的系列請寫完整。
- **同組月銷取沒被排除那幾家的最大值**：列 12（10萬+）到期被排除，組的月銷就是列 13 的 3萬，跟預期一樣。

## 4. 規則檔不清楚或互相打架的地方
這些都寫進 README 工單 #6 的「建議」段，由本機決定要不要改 json；程式不用動。
1. **`same_flavor_max_reject`（≤2）跟 `same_product_min_stores`（<4）重疊**：口味不同已經分成不同組，所以同組家數就是同口味家數；≤2 一定也 <4，只差理由文字。
   - 我照字面兩條都檢查，列 5 會同時寫兩個理由，預期結果允許多寫。
   - 如果「同款家數」本意是**跨口味合算**（同品牌同系列所有口味加起來 ≥4 家），規則檔要寫清楚，程式要多算一個數。
2. **前台欄空白、但 CSV 自己就有 ≥4 家**：`_same_product_min_stores` 一句說「家數＝max(前台, CSV)」，一句說「前台欄空白 ⇒ 標待數」，這種情況兩句說法不一樣。
   - 我照 max 顯示「N（CSV）」，不標待數（測試有一條）。樣本裡沒有這種情況。
3. **月銷讀不到**（不是空白、是看不懂的字）：規則沒寫。我不排除，標「月銷讀不到」，排在同層最後，交給人。
4. **「熱賣商品」字典是空的**：只能靠 CSV 的品類欄直接寫「熱賣商品」進來。後台頁面如果沒有品類欄，這類永遠對不到。
5. **新舊包裝字、價格區間、紅茶**：見 README 建議段。
6. **分潤加碼欄空白**：規則只講「不是加碼」。我把空白標「分潤加碼待查」，跟「否」（標「不是分潤加碼」）分開。
